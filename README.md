# Space Game

Космический шутер на pygame: реактор и конденсатор, четыре вида оружия,
три типа врагов с ИИ, волны, лут и кнопка самоликвидации — взрыв тем сильнее,
чем больше энергии на борту.

## Играть в браузере
После сборки через GitHub Pages: `https://ВАШ_НИК.github.io/ИМЯ_РЕПО/`

## Локальный запуск
```
pip install pygame
python main.py
```
Проверка боевой логики без окна: `python main.py --smoke`

## Управление
- Мышь — прицел
- W / S — тяга больше / меньше
- ЛКМ — огонь
- 1..4 — рельсотрон / лазеры / атомные ракеты / плазмопушка
- R — удерживать 3 с: самоликвидация (урон взрыва зависит от запаса энергии)
- ESC — выход

## Сборка для GitHub Pages
Файл `.github/workflows/pygbag.yml` собирает игру в WASM при каждом push
в ветку main и публикует её на Pages. В настройках репозитория:
Settings -> Pages -> Source: GitHub Actions.
Первый запуск занимает 2-3 минуты (вкладка Actions).
